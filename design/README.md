# Table Monsters visual reference

These design references were recovered unchanged from Git commit
`9d2a3fb2729d37698226bea4f41f930c280a0a38`, the latest original Next.js
Table Monsters design. The theme was introduced in `3c9fb44`; later commits
refined the torch glow, game details, and renown display. The original deployed
Next.js assets independently confirm the typography and branding.

`DESIGN.md`, the mapping, HTML mockups, and screenshot describe the visual
reference. `THEME-TODO.md` records that historical implementation, rather than
the current Rust migration status. The application retains the newer autosave,
difficulty ratings, accessibility, and historical-score behavior.

The current theme lives in `web/src/app/globals.css`. Font origins and licenses
are documented in `web/public/fonts/README.md`.
